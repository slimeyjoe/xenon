3. INSTALLING AND STARTING
==========================

Unpack the archive where you want the game, for example:
    lha x xenon-amiga-1.4.lha Games:
This creates the drawer "Xenon" with the program, its icon and this
ReadMe.

The game's data
  The archive does not contain the game itself. Its pictures, music and
  scripts belong to the original release (C's Ware, 1994) and go into one
  data file, xenon.pak, which you make from your own copy of the PC-98
  game: the five floppy disks or an installed hard disk, as disk images
  (D88, HDI, NHD, ...) or as plain files. On a computer with Python 3, in
  the source distribution:
      make data SRC=<your copy of the game>
      make pack
  (docs/game-data.md there explains it). It checks every file against
  the original release before using it. A xenon.pak someone else made
  for this version of the game works the same way. Put xenon.pak into
  the drawer "Xenon", next to the program (or give its place with PAK=,
  section 5).

From Workbench: open the drawer and double-click the XENON icon.
From the Shell:
    cd Games:Xenon
    xenon
Options go on the command line, for example "xenon LANG=ja AUDIO=ahi".
"version xenon" in the Shell shows which version you have.
From Workbench they are tool types of the icon (section 5).

Saved games go to the drawer "saves" inside the game's drawer. The game
creates it on first use. If the game's drawer is write-protected (a CD, for
example), saves go to ENVARC:Xenon instead. If neither works, they go to
T: and are lost when you switch the machine off.

Save files of the PC-98 version cannot be loaded.

Voices (optional)
  The Windows 95 version of Xenon (1997) has the characters speak most of
  their lines. This game can play those voices with its text, in every
  language (the voices are Japanese). They are not in this archive: the
  voice data file xenon_voice.pak is made from your own copy of the
  Windows version (its file XENON.DAT) with the tools of the source
  distribution (make voice-pack, described in docs/voice.md there). Put
  xenon_voice.pak in the game's drawer, next to xenon.pak; the game finds
  it at start-up (or give VOICEPAK=, section 5). NOVOICE turns the voices
  off again.
  There are two kinds of voice data. The 68k version needs the original
  one (make voice-pack CODEC=ldp6, 261 MB): the smaller Opus one (48 MB)
  takes far more processor time than a 68k has, and the 68k version
  cannot read it. The WarpOS version reads both.
  Put the voice data on a PFS3 or SFS partition if you can. The Fast File
  System is slow at seeking in a file this large, which shows as pauses
  when a line starts after a jump in the story (loading a game). On FFS,
  give the partition more buffers (AddBuffers, section 2).
  The voices play on the two Paula channels the music leaves free, with
  no extra mixing; with PAULA14 or VOICEMIX they are mixed into the music.
  With AUDIO=ahi they play as a second AHI channel: AHI mixes everything
  at the frequency set for the unit in the AHI preferences, so set 44.1 or
  48 kHz there for the voices' full quality.

The WarpOS version
  The archive xenon-warpos-<version>.lha holds the same game built for the
  PowerPC under WarpOS: install and start it the same way. Its saves are
  compatible with the 68k version. It needs WarpOS (WarpUP 5.x) set up for
  your board; "version xenon" names it "WarpOS". The game runs on the PPC,
  the 68k only handles the system calls and the sound interrupt.
  It has been tested in an emulator only (WinUAE's Blizzard PPC
  emulation), which cannot show its real speed or prove that it works on a
  real board. Reports from PPC owners are welcome.
