4. CONTROLS
===========

4.1 Keyboard

  Cursor Up / Down, numpad 8 / 2
      Move the highlight in a menu.

  Return, Enter, Space
      Choose the highlighted menu item. Turn the page of text.

  Esc, numpad 0
      Cancel in a menu (see 4.3 for what that does where). On a page of
      text, turns the page, just like Return.

  Help
      In a story menu, opens the system menu directly (see 4.3).

  Ctrl (hold)
      Fast-forward. Pages turn as soon as they are drawn, pauses are
      cut short and fades become instant. It stops at every menu.

  Caps Lock
      Text speed of the Japanese text (LANG=ja). With Caps Lock off,
      Japanese text appears one character after another, with Caps Lock
      on each page appears at once. It stands in for the PC-98's KANA
      lock key. English and Polish text always appear at once, as English
      text did with the PC-98 English patch.

  Shift+Esc
      Quit at once, from anywhere, without asking. Use it with care:
      progress since your last save is lost.

  Left Amiga+N, Left Amiga+M
      The usual Amiga screen keys. Left Amiga+N shows the Workbench,
      Left Amiga+M cycles through the screens and brings the game back.
      The game does not pause in the background: the music plays on.

  F10
      In a window (WINDOW): the next size that fits on the screen, in
      the order 1x, 1x 4:3, 2x, 2x 4:3, 3x, 3x 4:3, then back to 1x.

  Ctrl+C in the Shell the game was started from
      Asks the game to quit.

  Holding a key repeats it, as set in your Input preferences. Cursor Left
  and Right, numpad 4 and 6, and F1 to F5 are read but the game has no use
  for them. All other keys are ignored.

  In a window (WINDOW) the close gadget asks the game to quit, like
  Ctrl+C in the Shell.

4.2 Mouse

  The mouse pointer is hidden. As on the PC-98, the position of the mouse
  does not matter, only its movement: each push of the mouse up or down
  moves the menu highlight by one item.

  In a window (WINDOW) the pointer stays visible and is not the game's:
  pointing at a menu item does not choose it, moving the mouse still
  steps the highlight, wherever the pointer is. The click that brings
  the window to the front only does that; the next one is a Return.

  Left button   = Return: choose, turn the page.
  Right button  = Esc: cancel, turn the page.

4.3 Menus, saving and quitting

  The title screen offers GAME START, DATA LOAD and SPECIAL MODE.
  - GAME START begins a new game. The prologue offers more routes as you
    reach more endings.
  - DATA LOAD loads one of four saved games.
  - SPECIAL MODE holds the picture gallery (LADY'S ROOM) and the music
    player (MUSIC MODE). Both stay locked until you have seen all seven
    endings. Esc here returns to the title.
  The title screen itself has no cancel and no quit item. Use the system
  menu during a game or Shift+Esc.

  Saving. You cannot save at any moment. The story offers to save at fixed
  points, usually at the start of a chapter, with a menu asking whether to
  save or continue. Pick a save slot from 1 to 4 there.

  The system menu. While the story shows a menu of choices, Esc, the right
  mouse button or Help opens the system menu:
      Cancel                   back to the choice
      Return to the beginning  back to the title screen
      Quit the game            asks again, then returns to the Workbench
  In a menu nested inside another one, such as the list of save slots,
  Esc and the right button go back one level instead. Help always opens
  the system menu.

4.4 Voices

  With the voice data installed (section 3), a line's voice starts with
  its text. The arrow that asks for a key appears when the voice has
  finished. Return or the left button before that cuts the voice and
  shows the arrow (VOICESTRICT: they wait for the voice instead); Esc
  or the right button always cuts it. Holding Ctrl skips the voices
  along with the text.

4.5 Peculiarities inherited from the PC-98

  These are how the original works. The port keeps them on purpose.

  - The system menu is only reachable while a choice is on screen. During
    the text there is no way to leave the game except Shift+Esc (or the
    close gadget in a window, or Ctrl+C in the Shell). (The PC-98 version
    had a similar emergency exit: XFER, ROLL UP and ROLL DOWN held
    together.)
  - Ctrl fast-forwards through everything, including text you have never
    read. The game does not remember which text you have seen.
  - In the story menus, the keyboard wraps the highlight around from the
    last item to the first. The mouse stops it at the ends. The title
    screen menus never wrap.
  - Esc and the right mouse button turn the page of text. Pressing Esc
    repeatedly to "get out" of the story just reads on until the next
    choice, where it opens the system menu.
  - The game keeps running when its screen is in the background.
