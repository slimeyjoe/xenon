# Extra 8x16 glyphs for the Latin table lat8.xfnt (tools/xfont.py merges this file over the Sony
# 8x16 ISO 8859-1 font): the Polish letters. Same conventions as the PCF they extend: one cell
# per glyph, 16 rows of 8 pixels, '#' = ink, NOT emboldened (xfont.py applies the same bold as
# to the Sony glyphs). The baseline is row 13, rows 14-15 are the descender.
#
# ó and Ó are not here: the Sony font has them. The rest were drawn 2026-11-09 from the Sony
# glyphs themselves: base letter + diacritic. Acute = Sony's own
# from é / É; capitals with an accent lose two body rows, as Sony's É does, so the accent fits
# in rows 0-2; dot above 2x2; ogonek a two-row hook under the right side; stroke a diagonal
# through the stem. Edit freely: this file is the source, nothing regenerates it.
#
# Block: "U+XXXX <char>" then 16 rows.
