# Xenon script catalog and route graph

All 40 `.CC` files of the HDD install (`resources/original/game/`). Derived from the decompiled
listings in `resources/scripts/listing/` (generated by `re-tools/ccdis.py --export`); every jump,
menu and flag below was read from the bytecode (**verified**); story summaries are short
characterisations from the text (**inferred**, not a translation). Cross references:
`resources/scripts/graph.tsv` (all FILE/EXIT/COMPLETE/STAFFROLL with their page/label/IF context),
`summary.tsv` (counts per file), `assets.tsv` (every image/music/ADT/script/save/disk name),
`flags.tsv` (flag reads/writes per file). Engine mechanics: [scripts.md](scripts.md),
opcodes: [opcodes.md](opcodes.md).

## 1. How the engine starts scripts (verified, `game_main` 0ABA:01DC)

* Startup reads one byte from `XEN.GDT` into `DS:06E8` (progress bits; COMPLETE n sets bit n-1).
* Title menu (`title_menu_select`): **Start** -> clear flags, `s00` if bit0 = 0; else `s00c` if
  bit1 = 1 and any of bits 2-5 (0x3C) = 1; else `s00b` (0ABA:02C7..02F8).
  **Load** -> `l` (L.CC). **Omake** -> sub-menu: CG -> `k`, music -> `m`, each only if
  `(DS:06E8 & 0x7F) == 0x7F`, otherwise a "please finish the game first" notice.
* Before any of these, flags are zeroed (`flags_clear_all`), the image name is cleared, and the
  graphics page is cleared (0ABA:038D..03A9).
* Run loop: `cc_load(DS:137E)`, `cc_run`, `cc_free`, repeated while neither DS:13A6 (EXIT / system
  menu "return to start" / error) nor DS:13A8 (quit) is set. `FILE "x"` overwrites DS:137E, so the
  loop continues with `x.cc` (flags kept). `EXIT` returns to the title screen; LOAD (in L.CC)
  replaces DS:137E/page/flags from the save file and continues the same loop.

## 2. Progress bits and endings

| COMPLETE | bit | Where | Ending card |
|---------:|----:|-------|-------------|
| 1 | 0x01 | S0111 PAGE 1 | ＤＲＥＡＭ＿１ ‥‥ ＥＮＤ |
| 2 | 0x02 | S0207 PAGE 6 | ＤＲＥＡＭ＿２ ‥‥ ＥＮＤ |

| 4 | 0x08 | S0306A PAGE 2, `IF F139 == 1 && F151 == 0 && F152 == 1` | ＤＲＥＡＭ＿３β ‥‥ ＥＮＤ |
| 5 | 0x10 | S0306A PAGE 2, `IF F139 == 1 && F153 == 0 && F154 == 1` | ＤＲＥＡＭ＿３γ ‥‥ ＥＮＤ |
| 6 | 0x20 | S0306A PAGE 2, `IF F139 == 1 && F151 == 1` or `IF F139 == 1 && F153 == 1` | ＤＲＥＡＭ＿３δ ‥‥ ＥＮＤ |
| 7 | 0x40 | S0403 PAGE 2 | ＤＲＥＡＭ＿∞ ‥‥ ＥＮＤ |

Each ending is `COMPLETE n`, `STAFFROLL` (0E31:05D2), the end card, a key wait, and EXIT (title).
Consequences: the first play always goes to DREAM_01; DREAM_02/03 open after DREAM_01; DREAM_04
opens after DREAM_02 **and** at least one DREAM_03 ending; the omake needs all seven bits, i.e. all
four DREAM_03 ending types α, β, γ, δ.

## 3. Global route graph (verified)

```
title ─ Start ─┬─ bit0=0 ───────────────► S00 ─────────────────────────────► S0101 (DREAM_01)
               ├─ bit0=1, not S00C ─────► S00B ─ P6 "stay" ─────────────────► S0301 (DREAM_03)
               │                                └ P6 "hide" ─────────────────► S0201 (DREAM_02)
               └─ bit1 && (bits&0x3C) ──► S00C ─ P5 D2 "call the nurse" ────► S0101 (DREAM_01)
                                               ├ P5 D1 "leave the room" ────► S0401 (DREAM_04)
                                               └ P5 D3 "examine room" ─ P23 ┬ "stay" ► S0301 (DREAM_03)
                                                                            └ "hide" ► S0201 (DREAM_02)
DREAM_01: S0101 → S0102 → S0103 → S0104 → S0105 → S0106 → S0107 → S0108 → S0109 → S0110 → S0111 ⇒ end 1
DREAM_02: S0201 → S0202 → S0203 → S0204 → S0205 → S0206 → S0207 ⇒ end 2
DREAM_03: S0301 ─ P1 D1 "toward the footsteps" (F154=1) ─► S0301B ─► S0302B
          S0301 ─ P5 D1 "Tracy, explain" (F152=1) ──────► S0301A ─► S0302A ─► S0303A ─► S0304A ─► S0305A ─► S0306A
          S0301 ─ P5 D2 "Lanhua, you explain" (F154=1) ──► S0302B ─► S0303B ─► S0304B ─► S0305B ─► S0306B ─► S0306A
          S0306A: ending chosen by F139/F151..F154 ⇒ ends 3..6
DREAM_04: S0401 → S0402 → S0403 ⇒ end 7          (no menus at all)
Load:  L ─ "load" ─► LOAD saveN (resumes the saved script/page)   ─ "menu" ─► EXIT
Omake: K (CG gallery) ─► EXIT          M (music mode) ─► EXIT
```

S0301B joins the B branch at S0302B (S0301B P6 -> s0302b). In the S0301 P1 D1 case the B branch is
entered with F154 = 1 as well, so both ways into B set F154.

DREAM_03 ending flags (verified):
* F152 = 1: S0301 P5 D1 (A branch) · F154 = 1: S0301 P1 D1 / P5 D2 (B branch).
* F139 = 1: S0302A (A) or S0303B (B), option "　◆ バスルームの様子を見に行ってみよう‥‥。"
  (go and look at the bathroom).
* F151 = 1: S0304A (A), F153 = 1: S0305B (B), option "　◆ 惑星エイレートで過ごしたときのことを‥‥。"
  (talk about the time on planet Elath).
* Ending: F139 = 0 -> α; A: F151 = 0 -> β, F151 = 1 -> δ; B: F153 = 0 -> γ, F153 = 1 -> δ.

## 4. Per-file catalog

Columns: pages = PAGE count; menus = SEN count (incl. save menus) / options; saves = save points
(a "セーブする / ゲームを続ける" menu with 4 `SAVE saveN` slots); disk = DISK prompts (floppy
version only; letters = disk the following data lives on).

Settings (inferred from text and image names): the **hospital** ("medical centre") where 宏治
(Kōji, the patient) is treated by the hypnotherapist 涼子 (Ryōko) and meets 舞 (Mai), 恵 (Megumi),
沙夜香 (Sayaka) - backgrounds `1010`..`1070`; and the **dream**: the space ship of the space pirate
コウジ (Kōji) with ファル(ネリア) (Farnelia), ランファ (Lanhua), トレイシー (Tracy), ビアンカ (Bianca)
- backgrounds `0010`..`0130`. `waku`/`waku2` are the window frames, `*_bast`/`*_ba_b` character
busts, `*_m` eye-blink strips, other names character CGs.

### System scripts

**L.CC - load menu** (started by title "Load"). PAGE 0: TEXTPOS 10,313; `SEN "ゲームの続きをロードする" -> D1 (JMP 1) / "メニューへ戻る" -> D2 (EXIT)`.
PAGE 1: `SEN "データ１..４をロードする" -> LOAD "save1".."save4"`. LOAD restores script name, page and
flags from `saveN.dat` and resumes there (op_load 088D:1441; behaviour on a missing file: see
save-format.md). Cancelling a menu opens the system menu. No flags used.

**K.CC - CG gallery "ＬＡＤＹ’Ｓ ＲＯＯＭ"** (title Omake -> CG, needs all 7 progress bits). PAGE 0:
title card, loads `waku`/`waku2`, music `xenon_06`, JMP 1. 59 picture pages numbered 1-8, 10-14,
16, 100, 101, 17-55, 58, 59 (linked by explicit JMPs, so the gaps do not matter): one CG each (`WINDOW 1`,
`G_LOAD name` [+ `G_SABUN_LOAD` variants], `G_EFFECT 1`), menu "◆ 先に進む" (next) / "◆ 前に戻る"
(previous); page 1 also "◆ 最後尾に進む" (jump to last) and "◆ メニューに戻る" (EXIT), the last
page "◆ 最初の絵に戻る" (first) / previous / "メニューに戻る" (EXIT). DISK prompts B..E switch floppies
as the gallery advances. 58 G_LOAD of CGs (+ `waku`, `waku2`) and 18 G_SABUN_LOAD variants,
covering the CGs of all chapters. **Bug**: PAGE 23 is defined twice (0x0840 `r&m02`, 0x0893 `r&m03`); every `JMP 23` hits the
first, so the plain `r&m03` CG (second PAGE 23) is never shown (PAGE 24 shows `r&m03`+`r&m03b`).

**M.CC - music mode** (title Omake -> music, needs all 7 bits). One page: title "～ ミュージック
モード ～", background `music.gdt`, then for each of 17 songs `MUSIC_FADE 60, WAIT 60, MUSIC_LOAD
xenon_NN, MUSIC_PLAY, MSG "<title>{KEY}{W0}"` (title shown, waits for a key, no ▼), finally
TEXTCOLOR 15,0 and EXIT. Track list in order: xenon_01 Desert Storm, 02 XENON, 03 Lanhua, 04 蝶,
05 << QUADRA >>, 06 Ending II, 09 Synaps, 102 Ago, 11 Trust, 12 Silence, 13 Encoder, 15 Emergency,
16 Moon, 17 Dream, 21 Towering Past, 22 7th, 26 Mood (the titles come straight from the strings).
There is no menu: each key press (`{KEY}` = `wait_ok_key`) advances to the next song; after the last
one the script EXITs to the title.

## 6. Notes for translators / porters

* Option conditions are re-evaluated on every redisplay; menus loop until a case jumps, so option
  order and conditions are game logic, not cosmetics.
* Save points exist only where the scripts put them (PAGE 0 of most chapter files; S0104, S0106,
  S0202, S0305A, S0306B have two).
* Page numbers are referenced only by JMP within a file and by save files (DS:1294 page number +
  script name), so renumbering pages breaks old saves; offsets themselves are never stored except
  the resume offset computed at load time (save-format.md).
